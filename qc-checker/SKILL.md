# QC Checker - Final Gate

No video is delivered without QC report. If you only have screenshots, say clearly what could NOT be checked (audio, motion, transitions).

## A. Visual Check

1. First frame: Does it attract and explain video?
2. Opening line: Clear and strong?
3. Text timing: Appears / disappears in sync with voice?
4. Spelling: Any Arabic / English errors?
5. Text position: Does it cover face or important element?
6. Audio transitions: Any sudden cuts?
7. CTA: Clear, single, suitable for audience?

## B. Brand Check (Critical)

- [ ] Logo matches original file in repo 100%
- [ ] Colors match brand tokens (check hex)
- [ ] Background is #050810, not pure black #000000
- [ ] Rising Pixels present at start (unless user said no)
- [ ] Slogan Build. Innovate. Teach. present at end, word by word
- [ ] Arabic name ديجيتال نوى written correctly, letters connected
- [ ] Font is Space Grotesk Bold / Cairo Black, not generic

## C. Facts Check

Compare with user-provided trusted data: Prices, Names, Handles, Dates, Offers.
Do NOT assume video info is correct. Compare to source. If no source provided, mark as Unverified - do not claim verified.

## D. Issue List Format

For each issue provide: 1. Timestamp / location, 2. Problem description, 3. Exact fix required, 4. How to verify fix.

## E. Priority Order

1. Wrong info / misleading price / name / date
2. Brand error (logo / color / Arabic text)
3. Audio unclear / text unreadable
4. Weak CTA / weak hook
5. Minor polish

## Final Output

- Status: PASS / FAIL + Reason
- List of issues sorted by priority
- If PASS: Ready to publish + suggested caption + hashtags
